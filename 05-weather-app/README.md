# Weather App

Select a city from the dropdown and get live weather data including temperature, humidity, wind speed and conditions.

## Cities

New York, Los Angeles, Chicago, Paris, Tokyo, London

## Key concepts

- `async/await` with `fetch` to call a live weather API
- Optional chaining `?.` for safe access on nested response objects
- N/A fallback for any missing values from the API
- `location` is a reserved browser global so the element variable is named `locationEl`
